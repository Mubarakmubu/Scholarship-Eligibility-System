# Scholarship Eligibility & Application System

A web-based Scholarship Eligibility and Application System developed using Python, Flask, MySQL, HTML, and CSS.

## 📌 Project Overview

This project helps students check their scholarship eligibility based on predefined criteria such as family income, academic marks, category, and EWS status.

The system also recommends suitable colleges and allows eligible students to submit scholarship applications through the web application.

## 🎯 Objectives

- Student registration and login
- Student dashboard
- Upload scholarship-related documents
- Extract information from PDF and DOCX documents
- Check scholarship eligibility
- Recommend suitable scholarships
- Recommend eligible colleges
- Submit scholarship applications
- Generate a unique Application ID
- Store application information in MySQL

## 🛠️ Technologies Used

- Python
- Flask
- MySQL
- HTML5
- CSS3
- Jinja2
- PDF/DOCX document processing
- Git & GitHub
- Visual Studio Code

## ⚙️ Eligibility Criteria

The current implementation uses rule-based eligibility checking.

Example conditions:

- Family income ≤ ₹2,50,000
- 10th percentage ≥ 60%
- 12th percentage ≥ 60%
- SC / ST / OBC category or EWS eligibility

If the required conditions are satisfied, the student is marked eligible.
